## Overview

Predicting thermal comfort in electric buses using machine learning. This study developed a **PyTorch classifier** that improved prediction accuracy by **1.5% over the state-of-the-art** — using only **278 survey samples**, demonstrating the viability of ML approaches even with small datasets.

**First-author publication** in Applied Sciences (2023), 1,100+ views.
